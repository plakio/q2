# P2020 source audit

Audited repository: [oscarhugopaz/p2020](https://github.com/oscarhugopaz/p2020), commit `3f46704775efcf1b8f4ec906637b76fa2a0b3cee`.

## What P2020 itself provides

- Theme templates and responsive 2020 visual shell.
- Sidebar/menu/member presentation and front-end navigation.
- New Posts, New Comments, My Posts, and conditional My Mentions filters.
- Timestamp high-water marks in serialized `p2020_last_active` user meta, keyed by blog ID.
- Query alteration and CSS classification for unread posts/comments/mentions.
- Read-more/thread summaries in filter views.
- o2 configuration, labels, editor visibility, and theme-specific front-end affordances.
- WordPress theme support, Customizer integration, menus, widgets, editor styles, and translations.

## Dependency responsibility map

| Behavior | Owner in this stack | Evidence |
|---|---|---|
| Native content, users, roles, comments, threaded comment data | WordPress Core | Standard APIs/templates. |
| Front-end post composer/editing and application DOM | o2 | P2020 requires o2 and configures `o2_options`; its main content is replaced by o2. |
| Gutenberg composer/comments | P2tenberg + its wp.com companion | P2020 conditionally loads both and filters `p2tenberg_comment_editor`. |
| Mentions and autocomplete | Jetpack Mentions + private `inline-terms` code | `Jetpack_Mentions` gates My Mentions; wp.com files are referenced. |
| Notifications/browser push | Private WordPress.com notes modules | Loader references `notes/*`, Simperium, and Chrome push modules. |
| Likes | Jetpack/WordPress.com sharing infrastructure | P2020 toggles the `disabled_likes` option; it does not implement persistence. |
| Infinite scrolling | Jetpack Infinite Scroll | Filters `infinite_scroll_ajax_url` and query args. |
| Thread subscriptions | o2/WordPress.com subscription APIs | Overrides auto-subscribe hooks; site Follow shim calls `wpcom_subs_is_subscribed`. |
| New Posts/New Comments | P2020 | Theme query code and user-meta high-water marks. |
| My Posts | P2020 + Core author archive | Nonced author route. |
| Resolved/unresolved | o2 option plus internal-only conditions | P2020 only exposes this for Automattic checks that return false in this port. |

## Architectural findings

The repository is not a standalone implementation of the 2020 experience. Its README requires o2. Several loaders refer to files that only exist in a WordPress.com environment, while mentions, likes, notifications, and complete subscriptions remain external. P2020 should therefore be read as a UX adapter and integration map, not reused as Q2’s runtime or architecture.

The high-water unread model is cheap but imprecise: opening a filter advances a timestamp for everything, and per-item read/seen behavior depends on unavailable internal `FeedBag`/seen-posts code. Q2 needs indexed per-user event state for correctness and scale.

## Q2 replacements

- React application shell instead of theme template takeover.
- Core REST/core-data instead of o2’s custom front-end application protocol.
- Current block-editor packages instead of P2tenberg.
- Q2 mention extraction/indexing instead of Jetpack/private inline terms.
- Q2 notification, read-state, follow, and reaction tables instead of wp.com/Jetpack services.
- Cursor pagination instead of Jetpack Infinite Scroll coupling.
